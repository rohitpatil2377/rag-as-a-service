# RAG AS A SERVICE — Platform Brief

RAG as a Service is a sovereign, multi-tenant Agentic RAG-as-a-Service platform.
It turns an organisation's private documents into accurate, source-cited, AI-answerable knowledge.

The platform's uptime target is 99.5 percent baseline and 99.9 percent at peak.
The P95 query latency target is 3 seconds or less for hybrid retrieval with reranking.

Every answer carries source citations, and the platform abstains when retrieval confidence is low.
All components are self-hosted on your own infrastructure, so no data leaves it.

Retrieval combines dense vector search and BM25 keyword search, fused with reciprocal rank fusion.
A cross-encoder reranker then selects the most relevant passages before grounded generation.
